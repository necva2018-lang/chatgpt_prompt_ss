## 素材及本意

助理以內建 imagegen 生成無品牌米白帆布托特包原圖，兩個焦糖提把、袋口及方形底結構合理。沒有使用使用者素材。原圖、兩張成果及完整提示詞保存於 output/imagegen/stage-1-02。

- /luxuryedition：保留托特輪廓、雙提把、開口及方形袋身；材質確實由帆布變成巧克力棕皮革，能看見細緻車縫、包邊及香檳金屬配件，符合產品本身升級的本意。
- /storefrontmockup：同款米白托特包以攝影海報呈現在兩扇櫥窗內，門楣使用呼應提把的焦糖弧線；店面、玻璃入口及人行道可辨，活動跨店面呈現，入口保持分開。
- 兩張首次生成成果通過，未重試。五項預期與實際所見、來源提示詞、原圖／成果／實際提示詞 SHA-256 存於 database/media-batches/stage-1-02.json。
