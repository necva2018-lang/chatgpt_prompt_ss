## 一、思考與分析類

如果你不只是想讓 GPT「回答」，而是希望它幫你多想一層，可以使用這類指令。

### /think深入思考問題。

```javascript
/think 幫我判斷這份銷售資料最適合使用哪些 Excel 函數分析
```

---

### /blind-spot找出你可能忽略的盲點。

```javascript
/blind-spot 幫我檢查這份 Excel 報表可能忽略了哪些問題
```

---

### /devil站在反方角度挑戰目前的想法。

如果你已經有一個方案，但怕自己想得太單一，可以用它找出反對理由。

---

### /root-cause找出真正的問題原因。

```javascript
/root-cause 為什麼我的 VLOOKUP 明明有資料卻顯示 #N/A？
```

比單純問：「 ****為什麼 VLOOKUP 錯了？**** 」更容易把問題聚焦在原因分析。

---

### /first-principles用第一性原理重新拆解問題。

適合遇到比較複雜的工作流程、制度或決策問題時使用。

---

### /assumptions找出目前推論中隱藏的假設。

---

### /worst-case分析最壞可能發生什麼。

---

### /risk整理目前方案的風險。

## 二、比較與決策類

這組是我自己覺得在職場上非常實用的一類，因為很多工作並不是「找答案」，而是： ****A 跟 B 到底怎麼選？****

### /compare比較兩個工具、方法或方案。

```javascript
/compare VLOOKUP 與 XLOOKUP 的差異
```

如果你正在學 Excel，這個指令其實非常好用。

例如也可以問：

```
/compare SUMIFS 與樞紐分析表的差異
```

```
/compare Power Query 與 VBA 的差異
```

---

### /pros-cons直接分析優缺點。

```javascript
/pros-cons 使用 Power Query 整理每月報表
```

---

### /decision-matrix建立決策矩陣。

當你有 3～5 個方案需要比較時特別好用。

---

### /prioritize幫你排列優先順序。

```javascript
/prioritize Excel 新手最應該先學的 10 個函數
```

## 三、精簡與重寫類

ChatGPT 很常見的一個問題是： ****講太多**** ，這時候就可以直接使用以下指令。

```javascript
/no-fluff 解釋 Excel 絕對參照與相對參照
```

### /shorten把內容縮短。


---

### /human把文字改得更像真人。

很適合文章、社群貼文、Email 等內容。

---

### /bullet把內容改成條列。

---

### /table把資訊整理成表格。


### /tldr只給我超短摘要。

### /boss-mode用主管角度檢查內容。

```javascript
/boss-mode 用主管角度檢查這份 Excel 月報
```

這個滿有趣的，因為我們做報表時，很容易只站在「製作者」角度。

但主管真正想看的可能是：

- 這個月發生什麼？
- 為什麼？
- 哪個數字異常？
- 與上月差多少？
- 下一步該做什麼？

同一份報表，換個角色看，會完全不一樣。


這個在設計公司實際使用的公式時非常重要。

因為範例資料能成功，不代表放到真實資料也一定沒問題。
